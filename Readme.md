# Backend API - Project 2

A RESTful User Management API developed as part of the Full Stack Development Project 2.

## Features

- REST API
- GET users
- GET user by ID
- POST user
- Input validation
- Duplicate email detection
- HTTP status codes
- Error handling
- Health check endpoint
- JSON data persistence
- CORS support

## Technologies

- Node.js
- Express.js
- JavaScript
- REST API
- JSON
